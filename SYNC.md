# Product Owner Parity Note

The AI System Sync Compiler is retired. Nothing regenerates the Claude Project package anymore. The kernel and every knowledge file under `claude project/` are written by hand from the skill sources, following the manual parity method:

1. After a skill change, list `sk-product-owner/SKILL.md` against `claude project/Custom Instructions.md`, and each `sk-product-owner/references/*.md` or `sk-product-owner/assets/**/*.md` against its `claude project/knowledge/*.md` counterpart by name. Flow Mode's two sources sit in `sk-create-figjam/references/` and `sk-create-figjam/assets/` and are listed the same way
2. Decide which paragraphs apply inside a Project: drop loading conditions, routed-by lines, file-path routing and benchmark references, keep the decision rules, output shapes and examples
3. Check the read-only drift list: a skill file whose last commit is newer than its Project counterpart means a review is due
4. Record each review as a dated sentence below or in the system README: who reviewed, what changed, what was decided

No manifest, lock file or checksum ledger is kept. The old `claude-project.sync.json`, `package-lock.json` and the generated regions were archived when the compiler retired.

- Bump the version in the `Custom Instructions.md` H1 in the same change that edits it. That number is what a Project reader sees, and a kernel whose rules moved while its version stood still is a kernel nobody can date. A rule change is a minor bump, a wording or typo fix is a patch.
- The two version fields are independent on purpose. `Custom Instructions.md` carries the kernel's own H1 version, currently v1.2.4, and it moves when the kernel's rules move. `sk-product-owner/SKILL.md` frontmatter carries the skill version, currently 1.2.2.0, and it moves when the skill's rules move. The changelog under `sk-product-owner/changelog/` carries the four-part release stamp, which is a third scheme and belongs to the release rather than to either file. A skill number lower than a kernel number is not drift
