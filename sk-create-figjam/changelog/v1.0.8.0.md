# v1.0.8.0, Plan What the Board Shows

Claude Sonnet 5.5 high reran on v1.0.7.0 every scenario that had not passed and passed 2 of the 16 it ran. Composition was the largest cause. The models copy the shipped examples, and those plans left out parts the composer draws to read early. This release makes the glance rules and the examples plan what the board shows and closes the Left out, sticky and label gaps the rerun named. The composer itself is unchanged, so the Claude Project keeps its room for the model.

## What's New at a Glance

- **A state board starts where the eye does.** With no state named, the first state is planned first, because its light blue fill reads before anything else. A composite section reads as part of the frame, like the title block, and is never planned as a glance
- **Every early part is planned.** The light blue entry joins the goal, the final state, the gateway, the error and the critical bar as the kinds that read right after the accent, and the glance lines name every one the board draws
- **The examples plan what they draw.** The process, architecture, user flow and state examples now name the goal, the gateway, the entry and the first state they draw, so a plan copied from them holds on the board
- **What the board leaves out is always named.** A `Left out:` line appears whenever the board does not hold a cut, a split, a later board or a point the sources left open, and the gate carries the same line before the write. Every shipped example's gate now shows it
- **A sticky finds its place.** A node's own connector to its end dot no longer blocks the right side, a sticky with no free side goes where its line to the node is shortest and says so, and a sticky that lands badly is reported, never moved without a new yes

## Changed

- A same-title revision finds its old section as the tagged one with the earlier write time, and the delete question names that time beside the title
- The first board of a split is titled `1. Sign up` everywhere, so the start-here clause matches the title
- `flow_check.py` prints a `Label:` line, before the gate, for each node label the board would wrap with one word alone on its last line, so the model can shorten it. It never fails the check. The composer does not widen boxes for this, because the Claude Project sends the whole composer in every call and has no room to spare
- The playbook's Composition row counts a state board's composite as frame and costs one point for an unplanned part that reads at or before the planned second glance
- FJ-009's turn 2 ends on the gate that names the missing route. FJ-029 expects `1. Sign up`. FJ-038's PASS line asks for the second yes after the read-back. FJ-045 expects a light green goal that is not pink, the accented node as the first glance and three reader questions
