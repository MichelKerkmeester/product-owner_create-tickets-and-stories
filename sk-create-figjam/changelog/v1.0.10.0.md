# v1.0.10.0, The First State Leads

Claude Sonnet 5.5 high reran on v1.0.9.0 the 7 scenarios that had failed and passed 1. Every scored board had Composition at 0. On the state boards the composer drew the composite across the first column and top row, above the first state. On the flows the plans ordered nodes by fill while readers took the main row in path order. This release fixes both causes and widens the revision exemption.

## What's New at a Glance

- **The first state leads.** The composer lays an edge into or out of a composite against the composite's inner start, and the check refuses a composite with no inner start. A model that declares a label line such as `state "In stay" as InStay` before its transitions used to pull the composite into the first column and top row. Now the first state keeps the left and the composite follows it
- **Plans follow the path.** On a user flow or a process, every node the board draws sits in one of the three glance lines. The main row, the path from the entry to the goal, runs in path order after the outlined kinds and the entry, nearest the entry first, and two decisions share a line
- **A revision's whole main row waits.** On a revision whose changed end holds the second glance, every main-row node planned last costs no Composition point when it reads before the changed end

## Changed

- The user flow and process examples name every node they draw, the main row in path order
- FJ-017 expects a second sticky on an adjacent row below or to the left of its node
- The composer grows by 54 characters. The Project's composer code block is 47,599 characters on 156 lines, and the model and theme must stay under 2,410 characters. The largest shipped example model, the ER one, takes 2,401

## Upgrade

In the claude.ai Project, replace Assets - Flow Board Composer, Examples - Flow - Process, Examples - Flow - User Flow and Rules - Flow Quality Rubric. The kernel stays at v1.2.11.
