# v1.0.5.0, Smaller Calls and Stops That End the Turn

Claude Opus 5.5 medium ran 24 of the 54 FigJam scenarios on v1.0.4.0 before the operator stopped the run. Its boards were sound, but five things in the skill and three in the test driver got in the way. This release fixes them.

## What's New at a Glance

- **A call carries one builder.** `compose_board.py` now sends only the builder the model's type needs. A graph call drops the sequence and gantt builders, and a sequence or gantt call drops the layered layout. A graph model now has about 9,670 characters of room in one `use_figma` call, and a sequence or gantt model about 33,000, where every type had about 2,850 before
- **A named file is a valid target.** `references/flow-mode.md` Section 2 now lists an existing FigJam file the user named by its link or key as a target. The board goes in a new section beside what the file holds, and nothing on it changes, so it needs no plan and no `create_new_file`
- **Every stop ends its turn.** The playback and the gate are each the last message of their turn. A turn never ends on a status line after the stop's question, and a stop is never posted in the middle of a turn that goes on working
- **The scratch folder is deleted.** Section 2 gains a clean-up step before the reply. It deletes the one folder outside the repository that the check and the composer wrote to, so no model or code file outlives the write

## Changed

- The arrow primitives in `assets/compose-board.js` sit with the other primitives in Section 3, because the key draws them too and a graph call that drops the sequence builder still needs them
- `compose_board.py --design-check` reports the room per type, and the self-test proves each type's call carries its own builder and no other, 1,032 checks in all. `--template` with no model still prints the whole composer, which the Project mirror carries
- The playbook's hygiene rule exempts the board section that a gated extension widens to hold its notes, because `references/hybrid-workflow.md` grows it and returns its old size for the rollback. A board point no longer fails on that one change
- FJ-004 says a sandbox that leaves out `claude project/` prints a `SKIP` line for each Project mirror, which is expected there, because the repository gate runs the same self-test with the mirror present

## Upgrade

In the claude.ai Project, replace Templates - Flow Mode and Assets - Flow Board Composer. The Project keeps the whole composer, so its size and its room are unchanged. Kernel v1.2.5 is unchanged.
