# v1.0.21.0, Boards Edited by Hand and Bold Edge Labels

A hand-built timeline board for one team member showed where the packet had no rules. The user asked for columns to be inserted, the board to be widened and labels to be restyled. The packet forbade all three and said a FigJam file has one page, which a live write proved wrong.

## What's New at a Glance

- **A board edited by hand has a route.** `references/flow-mode.md` Section 9 sets a backup page before each structural change, a node map, label placement after every move, key line samples drawn between anchors and a render check
- **Stage-column boards have a grid.** `references/style-guide.md` Section 7 starts at a 660 pixel pitch and says what shifts and widens when a column is inserted
- **Edge labels carry Bold.** A short key before a colon, such as **Decline:** No impact, is Bold, and a decision exit of three words or fewer is Bold throughout. The composer sets it, and the model never writes stars
- **Companion documents stay in step.** `references/flow-mode.md` Section 8 lists the `.md` files and A4 pages a board has, carries each copy change into all of them and respaces an A4 page after its text grows
- **Two copy rules.** No word left alone on its last line, and a line break the user typed is kept as intent

## Changed

- `SKILL.md` NEVER rule 4 now reads "unasked" and points to the hand route
- `references/flow-mode.md` and `references/hybrid-workflow.md` no longer say a FigJam file has one page or that `figma.createPage()` throws
- `assets/compose-board.js` sets the Bold on edge labels and measures a Bold label in Bold, so its gap still fits it
- `assets/figjam-design.md` notes the Bold on the `label` row
- `references/quality-rubric.md` Section 6 adds four items: the hand route, stranded words, edge label weight and companion sync
- `scripts/compose-trace.mjs` keeps Bold ranges, and `scripts/compose_board.py --self-test` adds one check that proves the key, the short exit and the long label

## Upgrade

The Claude Project mirrors of Flow Mode, the style guide, the quality rubric, the hybrid workflow, the board design and the composer carry the same change. The `fj` route rollback line has no Project counterpart, because the Project leaves that route out.
