# v1.0.1.0, Composed Boards

The 2026-10-22 boards read correctly and looked poor: tall strips of grey outlined boxes with small labels, a loose title, no frame and tints laid on afterwards as overlapping blobs. Figma's `generate_diagram` owns its font, colour and layout, so no rule could fix that. Flow Mode now draws the board itself from the checked model.

## What's New at a Glance

- **A composer.** `scripts/compose_board.py` turns a checked diagram into the model `assets/compose-board.js` draws, and one `use_figma` call draws a framed board: a title and subtitle, the diagram on an 8 pixel grid, every shape sized to its text and coloured by its kind, tinted zones, routed connectors, a key of every mark the board uses and a source line
- **Board lines in the model.** `%% title:`, `%% subtitle:`, `%% source:` and `%% zone:` comment lines carry the board's text and grouping. The check ignores them, and the generated fallback strips them
- **Colour by meaning.** The one-accent rule is gone. Every kind draws in its own colour on every board, and a `style` line marks meaning only: the goal, a failure or the step in focus
- **A tagged board.** The composer tags the board section it draws with shared plugin data keyed by its title, so a later session finds it, and a revision composes the new board, reads it back and deletes the old one only after its own yes
- **Read-back by name.** Nodes are matched by the ids the write returned and connectors by their layer names, `edge:` and `leg:`, so a routed edge is followed through its anchors
- **Notes only.** `references/hybrid-workflow.md` now adds notes alone, as numbered pins with a sticky legend or single stickies inside the board. Titles, tints and keys moved into the composer
- **A design rubric.** `references/quality-rubric.md` Section 7 scores a board on eight criteria from 0 to 2, so two boards of one model can be compared

## Changed

- `references/flow-mode.md` names three write routes: composed first, `generate_diagram` when `use_figma` is not connected, then `fj`. The gate names `whoami`, `create_new_file`, the `use_figma` call and the `get_figjam` read-back
- `references/style-guide.md` records the colour of every kind, the type scale and the grid, and what a `style` line means. `linkStyle` passes the check and draws nothing
- Every type reference gains a Colour, zones and notes section and a Writing the board section. ER domains are `%% zone:` lines and state end states are coloured by the composer, so neither needs a tint
- A composite's inner entry and exit no longer colour its substates as the machine's first or final state
- The worked examples carry board lines, and their gates list the calls the write spends
- `benchmark/gates/run_gates.sh` runs the composer's self-test as a fifteenth gate

## Upgrade

The claude.ai Project has no script, so `Product Owner - Assets - Flow Board Composer` carries the composer's code with a guide to filling its model by hand, and the composer's self-test fails when that copy drifts from the code. When the code does not come back whole from Knowledge, the Project writes through `generate_diagram` and says so.
