# v1.0.22.0, the Direct Edit Has a Gate

A fresh review of v1.0.21.0 found that the skill gave two opposite answers to one request. One rule said a nudge is answered without a tool call, and the new route said to make it through `use_figma`. The route also had no gate, no read-back and no delete rule.

## What's New at a Glance

- **One answer to a move or restyle request.** The first reply calls no tool, names the change the model cannot carry and offers both ways: the user edits in FigJam, or Claude makes a direct edit after a yes
- **The direct edit has a gate.** The reply lists the edits, the backup page, what the read-back counts and the rollback, and only a yes to it writes. No node this edit did not create is deleted without its own yes
- **The render check follows the stale rule.** A direct edit is rendered with `node.screenshot()` inside `use_figma`, as Section 7 already requires after a later write
- **The router knows the route.** `route_flow` takes `direct_edit` and loads the style guide, the rubric and the hybrid workflow with no diagram type

## Changed

- `references/flow-mode.md` renames the route to A direct edit, defines a structural change and qualifies the two rules that forbade moving a composed node
- The composer bolds every label leaving a decision or a choice, keyed on the node's kind, so a design that remaps a colour role changes no weight
- Edge label wording names the boards it covers, keeps the 40-character cap, quotes a label with a colon and keeps the lowercase events a state board sets
- The two copy rules apply to a direct edit and its companions and keep the escape step 5 gives a composed label
- `scripts/compose_board.py --self-test` now proves a step's short label, a four-word key and a long decision exit, and the trace counts only a true Bold
- FJ-038 expects the offer of a direct edit behind its gate, still with no tool call

## Upgrade

The Claude Project mirrors of Flow Mode, the style guide, the quality rubric, the hybrid workflow and the composer carry the same change.

The trace sizes every weight alike, so the self-test does not prove that a Bold label is measured in Bold.
