# v1.0.7.0, One Board Is What the Words Say

Claude Sonnet 5.5 high reran on v1.0.6.0 the 31 scenarios v1.0.5.0 did not pass and passed 14 of the 27 it ran. A findings pass and a critic then named 35 findings across the skill, the composer, the playbook, the test driver and the run's records. This release fixes the skill, the composer and the playbook.

## What's New at a Glance

- **One board is what the words say.** A user asked for one board only when the request says one board, a single board or one diagram. Naming where the board goes, such as on a new board or in this file, is a destination and not a request for one board, so an oversized flow splits as before
- **Scope rides with the type question.** When a broad brief also fits two types, the first reply asks the type question alone and names the recommended scope inside its recommendation, and the next reply reads that scope back
- **A missing route still plays back first.** With no Figma route the intake and the playback run as usual, and the gate names the missing route in place of the plan and the calls, so its yes is to the missing-route reply
- **A leadership reader sets the dials.** A leadership, executive or management reader sets the Executive audience and the Simplified detail level, and the playback and the gate name all three dial settings by their words
- **The checks catch three more slips.** `flow_check.py` refuses a node that returns to itself on a user flow, a process or an architecture, and a state guard that names a state by its id. `compose_board.py --self-test` flags arrivals on one side of a node closer than 24 pixels where the side holds them

## Changed

- Every rule that applies when the user asked for one board now says asked in so many words, in Flow Mode, the templates and the seven type references
- The gate's call list adds one more read of a named file that already held content, so the read-back can compare it with the read before the write
- A label counted from the text a `get_figjam` read returned was read, not read visually
- A single sticky goes right of its node, then below, then above and left only when all three are taken and no connector runs between. A sticky right of a node in the last column is allowed and widens the board
- The rubric plans a goal, a final state, a gateway, an error and a critical bar second, because their 4 pixel outline reads right after the accent. A state board takes its order from the state reference instead
- A state board plans its composite first and its first state second unless the request names other states. A request about a group, such as the end states, puts the focus on its most telling member. A guard names the state by its label, never its id
- The user flow, process and architecture references say no node returns to itself
- A source that says every decision is logged draws the log store with one solid edge from the decision the reader most needs
- Gantt arrows into one bar land up to 24 pixels apart within 72 pixels of its left end, up from 16 within 48. `compose_board.py --self-test` runs 1,244 checks and `flow_check.py --self-test` runs 167
- The playbook scores Composition and Signal at full marks when the request names a group or a changed end the rubric keeps second, scores Fidelity against the run's own checked model and exempts the paired artifact's own re-save from the nothing-exported check. FJ-020 gains the second turn its later-round signal needs
