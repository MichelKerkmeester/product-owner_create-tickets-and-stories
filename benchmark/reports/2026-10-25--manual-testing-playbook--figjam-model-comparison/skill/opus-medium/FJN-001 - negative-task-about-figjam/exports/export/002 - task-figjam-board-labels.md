# Tidy the FigJam board labels

## About

---

Designers and engineers use this FigJam board as a reference during handoff. Its labels are hard to read and do not follow one naming rule, so people lose time working out which screen or step a label means.

The board holds 82 top-level sections across Roamstay, Loomlist and Fernhouse, and many diagrams appear several times under the same name. A reader cannot tell which copy is current. This task settles which sections stay, then brings every remaining label in line with one naming rule. The board owner signs off once the board is tidy.

### Requirements

---

1.  **Decide which duplicate sections stay**

---

Several section names repeat across the board. The board owner picks the one current copy of each before any label work starts, so nobody tidies a copy that is about to go.

| Section name | Copies on the board |
| --- | --- |
| `Start a return` | 11 |
| `Booking status` | 9 |
| `Stays model` | 8 |
| `Offline mode launch` | 7 |
| `Damaged-item refund` | 6 |
| `Booking status lifecycle` | 5 |
| `Change booking dates` | 4 |
| `2. Checkout payment, declined card` | 3 |

**Checklist**

- [] The board owner has named the one copy of each repeated section that stays
- [] Every other copy is removed only after the board owner names it for removal
- [] No section is removed without the board owner's say, including sections someone else drew

---

2.  **Every label in scope**

---

Once the duplicates are settled, the task covers the whole board, so no label is missed because nobody listed it. That includes section titles, sticky notes, connector labels and shape text.

The `Sprint retro` section is not a product diagram and is out of scope for this task.

**Checklist**

- [] Every section title, sticky note, connector label and shape text in the remaining sections has been reviewed
- [] No remaining section of the board is left out of the review
- [] The `Sprint retro` section is left as it is

---

3.  **One naming rule**

---

Labels follow one rule, so the board reads the same everywhere and matches the app it describes.

**Checklist**

- [] Every label uses sentence case
- [] Every label that names a screen uses the same screen name the app shows
- [] Spelling mistakes in labels are fixed
- [] A screen or step carries one name across the whole board, with no duplicate or outdated names left
- [] No placeholder label is left, such as the text node named `Text`

---

4.  **Known labels to fix**

---

These labels break the naming rule today. They are a starting point, not the full list.

5.  **Sign-off**

---

The board owner confirms the result before the task closes.

**Checklist**
