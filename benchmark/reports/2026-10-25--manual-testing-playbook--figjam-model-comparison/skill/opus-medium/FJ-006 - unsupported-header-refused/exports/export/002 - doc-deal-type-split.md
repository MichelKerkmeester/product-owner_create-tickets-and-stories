## Overview
* * *
This catalog lists each Barter deal type and the share of deals it makes up. It is for the product team, so they can see which deal types brands pick most. Trends over time, revenue per type and breakdowns by market are out of scope.

The shares are blank for now. The split in an earlier test model was made up to test a check and is not Barter data, so each share stays empty until a data owner supplies the real figure.
