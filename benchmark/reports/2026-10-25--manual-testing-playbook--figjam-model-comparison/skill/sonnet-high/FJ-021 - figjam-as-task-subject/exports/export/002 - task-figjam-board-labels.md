# Tidy FigJam board labels

## About

---

The labels on the FigJam board need to follow one casing style and one name per thing. A reader should find each screen or step under a single label and never wonder whether two labels mean two different things.

The task covers the whole board and every label type: sticky text, shape text, connector labels and section titles. It changes naming and casing only.

### Requirements

---

1.  **One name per thing**

---

A screen, step or element that appears more than once on the board carries the same label each time. This stops a reader from taking two labels for two different things.

**Checklist**

- [] Every screen, step or element shown more than once uses one label across the whole board
- [] Where labels for the same thing differ, the name the product uses is kept
- [] Labels for different things stay different

---

2.  **Sentence case**

---

Every label uses sentence case so the board reads in one style.

**Checklist**

- [] Every label is in sentence case, with the first word capitalised and the rest in lower case
- [] Proper nouns, product names and acronyms keep their own capitalisation

---

3.  **Full pass and boundaries**

---

Every label is reviewed so no old label survives next to a corrected one. The pass changes naming and casing only.

**Checklist**

- [] Sticky text, shape text, connector labels and section titles are all reviewed across the whole board
- [] No label is left in its old casing or under a duplicate name after the pass
- [] The meaning of each label stays the same
- [] No label or element is moved, resized, restyled or deleted
