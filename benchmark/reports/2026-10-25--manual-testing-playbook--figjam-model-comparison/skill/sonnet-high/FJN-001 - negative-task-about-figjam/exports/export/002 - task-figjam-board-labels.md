# Tidy the FigJam board labels

## About

---

The text labels on the FigJam board need tidying so the board reads as one coherent piece. Readers should scan it without stopping on mixed casing, uneven wording or text that spills out of its shape.

Only the labels change. The board's structure, content and meaning stay as they are.

### Requirements

---

1.  **Consistent label wording**

---

Every label follows one convention, so the same concept reads the same way wherever it appears on the board.

**Checklist**

- [] Every label uses sentence case
- [] Typos and spelling errors are corrected
- [] The same concept carries the same name on every label where it appears
- [] No label changes meaning, and no label is added or deleted

---

2.  **Legible labels**

---

Text sits fully inside its shape or beside its connector, so nobody has to resize or select a label to read it.

**Checklist**

- [] No label text overflows or is cut off by its shape
- [] No label overlaps another label, shape or connector
- [] Labels of the same kind share one text size

---

3.  **Board-wide check**

---

The work is done only when the whole board meets the two groups above, not just the areas that were edited.

**Checklist**

- [] A pass over every label on the board finds none that breaks the rules above
