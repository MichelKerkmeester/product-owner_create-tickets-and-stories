# Define the Fernhouse onboarding checklist

## About

---

Fernhouse needs one onboarding checklist that lists each step from the first step to the point where onboarding counts as complete. Each step has an owner and a stated done condition, so whoever runs an onboarding can see what is finished and what is left.

### Requirements

---

1.  **Steps and order**

---

The checklist lists every onboarding step once, in the order the steps happen, so nothing is skipped or done twice.

**Checklist**

- [] Every onboarding step appears exactly once
- [] Steps appear in the order they happen
- [] The checklist states the point at which onboarding counts as complete

---

2.  **Owners and done conditions**

---

Each step has one owner and one condition that marks it done, because a step without either cannot be checked off.

**Checklist**

- [] Each step names one owner
- [] Each step states what marks it done
- [] A step that depends on a decision names the decision and each outcome
