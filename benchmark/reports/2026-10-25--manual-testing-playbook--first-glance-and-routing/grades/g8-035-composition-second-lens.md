# Composition, second lens, round 035

Rule used: the Composition line of playbook Section 3. 2 means the board reads in the planned glance order and the element the request is about comes first. 1 means the order holds and one part comes before that element. 0 means two parts read in the reverse of the planned order. The quality rubric Section 3 puts the accent on the node the first glance names. The style guide Section 3 gives the accent an 8 pixel pink outline against 2 for every other node, and says the start pill cannot outweigh it in colour or in greyscale.

Plans come from each delivery reply's Read-back line and from its gate reply for the second and last glance. Only the overview and greyscale images were judged.

Reading of the scale. When the planned first glance reads first and only the planned second and last swap, I score 1, because the claim leads but the order does not fully hold. I keep 0 for boards where a part the plan placed later reads before the planned first.
