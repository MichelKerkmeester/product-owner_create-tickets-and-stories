# Conciseness, intended silence

Each block below sits one step short of a violation, so a check that fires
here is over-reaching rather than enforcing.

## Router token binding

The router binds an exact command token before it scores anything semantic,
because a keyword-first pass would bind the wrong intent.

## Export verification

Read the artifact back from the exact path and use the final line number as N.

## Hedge stacking

A malformed token might reach the fallback intake flow.

## Quoted vocabulary

"In conclusion" and "Overall" are named here as banned openers, not used as
openers, so a quoted mention stays silent.

## Fallback behaviour

A route with no command token and no framing falls back to the intake flow,
which asks one consolidated question and then waits.
