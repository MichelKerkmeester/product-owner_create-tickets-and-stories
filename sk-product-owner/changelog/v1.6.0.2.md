# v1.6.0.2, PRDs Follow the House Opening

The first part of a PRD or Story artifact now follows the team's real house opening, derived from the FS - Creator - Onboarding v2 ClickUp epic. The opening is an About narrative, then Problem, Solution, References and Expected Outcomes. Routing, tier, confidence and gate behavior stay as they are.

> Spec folder: `specs/ai-systems/034-product-owner-prd-opening-restructure/`

## What's New at a Glance

- **About is the narrative umbrella.** It holds scope, value and the user-story promise in prose, with an optional state/lifecycle map.
- **Problem and Solution leave About.** Their sub-blocks move out of the About block to H3 group sections, matching the Fv2.5 heading scheme.
- **The User Story block is optional.** About now carries the promise, and the Connextra block survives as optional enrichment 4.1, placed under Solution, for Complex epics that need explicit promise lines. Per-requirement `PRD:` value lines already cover requirement-level promises.
- **References is the single home for links.** It groups Components, Visuals, Flows and the governing spec, and the standalone Documentation enrichment is removed. References is required only when links exist.
- **Problem is optional at Simple.** A copy-tweak PRD may have no current state to break. Drop it when there is genuinely nothing to describe.
- **Expected Outcomes is required and explicitly split from Acceptance criteria.** Outcomes describe the epic-level why. Acceptance criteria verify the requirement-level what.
- **The template drops Coming up.** The source epic has the section, but the owner removed it from the template and the examples before release. The house format teaches About through Expected Outcomes only, and a team can still append the section to a real epic when they need it.
- **The kernel anchors major PRD sections at H2.** `Custom Instructions.md` now describes the new opening at H2. This corrects a pre-existing drift where the kernel anchored PRD major sections at H3 while the authoritative sources anchor them at H2.
- **A mandatory kernel review remains.** It is the remaining gate for the contract-input change, per `SYNC.md` section 5.
- **PRD mode and the four examples follow the new opening.** The create workflow and the quality checklist match the house shape. Simple trims and Complete shows the optional User Story block, the References sub-groups and the About lifecycle map.
- **Several blocks keep their existing status.** The blockquote preamble, the Mention line, DoR/DoD, Rule blocks, Which-means-that, value lines and the shared-mechanism section are unchanged.

## Upgrade

No migration required. The remaining gate is the mandatory kernel review for the contract-input change, per `SYNC.md` section 5.
