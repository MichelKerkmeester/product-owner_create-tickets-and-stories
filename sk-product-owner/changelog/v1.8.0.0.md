## [**1.8.0.0**] - 2026-09-17

Task Mode gains two table rules and a worked example taken from a shipped Barter design token release. A ticket table now carries at most 4 columns. A table of per-size values leads with Size in the leftmost column. The DS Variables example shows both rules on a parent task with one subtask per app, in the ClickUp format the team ships.

> Scope: the Task Mode and Task Templates source pairs, the new DS Variables example pair, both READMEs, the Project kernel version and the parity gate's pair map. No routing, command, confidence or delivery behavior changed. Fleet-wide changes that landed between 1.7.0.0 and this entry, such as the kernel statement moves, are recorded in git history and in `SYNC.md` rather than repeated here.

### Table rules

`references/task-mode.md` adds a Tables subsection under Structure Rules. A table carries at most 4 columns and splits into more tables that repeat the first column past that. A table of values that vary by size puts Size in the leftmost column with one row per size, one column per token or property. The Structure Validation checklist gains the matching line. The file version stays v0.303.

### DS Variables worked example

`assets/examples/task/task-example-ds-variables.md` holds the parent task `DS - Variables - v1.0.7 - Size Variables & Disabled States` with its Partner and Creator subtasks as shipped to ClickUp. Live attachment links became `clickup-attachment-url` placeholders. Export errors were corrected rather than taught: a parent About that contradicted its own rename table, a Creator About and requirement title copied from Partner, token names missing a leading dash, an empty table cell and spaced rem values. Task Templates points at the example from Parent Task and from Subtask. It is the one example in the library on a real product.
