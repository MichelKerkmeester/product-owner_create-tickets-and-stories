# v1.2.14.0, Screenshot Pairs Sit Side by Side in ClickUp

A design review reads a built screen against its Figma frame. Stacked one above the other, the two are hard to compare.

## What's New at a Glance

- **A pair becomes columns.** Section 7 Push Targets replaces each DEV and FIGMA pair with a `[[COLS-n]]` line on a doc page and runs the `mcp-click-up` columns routine after the gap pass
- **The export stays readable.** The local file keeps each pair as a `DEV` line and a `FIGMA` line above their images, with the Figma link on the label
- **Columns are protected.** A page that holds columns is never rewritten with `replace`, because the markdown read-back drops them
- **A task stays stacked.** A task description has no columns, so a pair pushed to a list keeps its two lines

## Upgrade

No Project file changes. A claude.ai Project pushes through its own ClickUp connector and cannot run the editor routine.
