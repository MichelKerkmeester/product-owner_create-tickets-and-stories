# v1.2.5.0, The Flow Reply Names What It Leaves Out

`SKILL.md` described the Flow route's `Left out:` line as appearing only when steps were left out. `sk-create-figjam` v1.0.8.0 names every cut, split, later board and point the sources left open, so this release states the same rule here. No template, example or other route changed.

## What's New at a Glance

- **One rule for the Flow reply.** The reply's `Left out:` line appears whenever the board leaves out a cut, a split, a later board or a point the sources left open, as `sk-create-figjam/references/flow-mode.md` Section 8 sets out

## Upgrade

No Knowledge file changes. Paste kernel v1.2.10, which the `sk-create-figjam` v1.0.8.0 note describes.
