# v0.17.2.0, The CLI Asks First Where the Kernel Does

A read-only comparison on 2026-10-01 held the CLI side against kernel v0.22.0. The kernel makes a promised source that has not arrived and a decision the user calls unsettled ask first for Task, Bug, Story, Epic and Doc. The CLI said so for Doc alone.

## What's New at a Glance

- **Two ask-first triggers cover every artifact kind.** `AGENTS.md` and `SKILL.md` now say that a promised source not yet sent and a decision the user calls unsettled each make the first reply one consolidated question with no draft, with or without a command. `$quick` skips routine intake but never either of them.
- **The router reference names the kernel as the carrier.** `references/router-contract.md` no longer says a `System - Router Contract` Knowledge document carries the router. The kernel carries it as Section 11, Router Code, with its comments removed.
- **Eight rule blocks lead with their topic.** "The kernel points here for ..." is gone from the router reference, because the kernel carries those rules itself.
- **The READMEs count 37 Knowledge files.** The Router Contract document left the folder in v0.17.1.0.
- **The kernel stays at v0.22.0.** No kernel line changed.
