## [**1.11.0.0**] - 2026-09-25

Six operator decisions from grading the 2026-09-25 Opus 5.5 medium playbook run. An explicit command always asks first, an Epic writes References only when a link is supplied, a promise to write a file counts as a file claim in a Project and a bug never asserts that no error message appears when none was supplied. In the playbook the Behavior reference scenarios draft at once from their attachments, and the two-platform log bug allows a cause labelled as an unverified hypothesis. Four are rule changes, so the skill moves to 1.11.0 and the Project kernel to v1.15.0.

> Scope: `AGENTS.md`, `SKILL.md`, the Bug Mode, Story Mode, Doc Mode, Interactive Mode, Interactive Response Templates, Epic Template and Bug Report Template source pairs, the Project kernel, the Sync Loop declaration, both READMEs, the playbook root and ten scenario files. No routing, confidence or export naming changed.

### Why

`AGENTS.md` and the kernel said `$task`, `$bug`, `$doc` and `$story` still ask their mode's question, and `references/task-mode.md` carried the same exception. Bug Mode, Story Mode and Doc Mode each let a request with enough context draft at once and named no exception for a command, and the Interactive Mode state machine sent `$doc`, `$story` and `$epic` straight to a gate that drafts whenever nothing is missing. The Epic scaffold and every Epic statement listed `#### **References**` with no way out, although none of the Epic scenarios supplies a link, so a correct Epic had to carry an empty block or an invented one. The Project kernel forbade claiming a save and said nothing about promising one. The bug template's Observed Behavior slot read "Any error messages displayed", and all three skill bugs in the run wrote "No error message is shown" when no ticket, log or turn said so. `SDK-001` and `PDK-001` expected a Turn 1 question from a request with no command whose attachments answer every field Doc Mode asks about. `SBG-003` and `PBG-003` passed only with "no root cause for either issue", which read stricter than the root's Defect severity, where a cause the artifact labels as an unverified hypothesis is not an invented one.

### What changed

- An explicit command routes the request and does not supply the direction. `$task`, `$bug`, `$doc`, `$story` and `$epic`, their short aliases and the `$prd` and `$p` aliases ask their mode's question and wait, however much context the request carries, and only `$quick` or `$q` may skip routine intake. The "draft when the context is enough" branch in Bug Mode, Story Mode and Doc Mode now applies to requests with no command. `SKILL.md` states it in the Clarification Protocol, Interactive Mode routes the Doc, Story and Epic commands to their clarification question before the gate and the Story Context Question is used for every explicit Story or Epic command
- An Epic's `#### **References**` carries supplied links only and is left out when none are supplied, never written empty or with an invented link, the rule the Story scaffold already stated. The kernel now says this for both shapes, so the Story reads no stricter there than its own scaffold
- The kernel's NEVER 3 forbids a promise to write or save a file as well as a claim that one was saved, because an export-equivalent path is a label and not a file the Project writes
- The Observed Behavior slot now asks for an error message the ticket, log or user supplied. With none supplied the line reads `Not provided` or is left out, and it never states that no error message appears. Bug Mode's Observed Behavior rule and its checklist item say the same on both sides
- The playbook root counts a promise to write or save a file as a Project-side file claim in the Identity handover rule and in Defect severity, and allows a follow-up change to a delivered doc to update that export in place or take the next number

### Playbook

`SDK-001` and `PDK-001` keep their Turn 1 input and attachments word for word. Turn 1 now drafts the Behavior reference at once in the doc lane, and Turn 2 is a follow-up change carrying the direction the old Turn 2 supplied. The rules do not settle whether that revision updates the delivered doc in place or saves on the next number, so the scenarios say so and do not grade the choice. Every value check the old Turn 2 carried still applies. The six Epic scenarios require References only when a link is supplied, never empty and never invented. `SBG-003` and `PBG-003` now fail a cause stated as fact or one cause given to both issues, and allow a cause the artifact labels as an unverified hypothesis, as the root's Defect severity already does. Both twins of every pair keep identical turns, 86 across the package.
