# v1.2.12.0, a ClickUp Push Checks the Logins First

A first-time user has to approve the ClickUp MCP once, and a doc page push also needs ClickUp logged in, in the browser the divider gap pass uses. Before this release the push found a missing login only when a write or the gap pass failed.

## What's New at a Glance

- **The check runs after the yes.** Section 7 Push Targets runs the readiness check in `../mcp-click-up/references/mcp-tools.md` Section 3 before the first ClickUp write of the session
- **A missing login is a question.** The user gets one structured question per missing piece, in the words the check gives, and the push waits for the answer and a recheck
- **A skip is reported.** When the user skips the gap removal, the push still lands and the reply names the gaps left

## Upgrade

No Project file changes. The claude.ai Project uses its own ClickUp connector, which handles its sign-in, and cannot run the check's Code Mode program.
