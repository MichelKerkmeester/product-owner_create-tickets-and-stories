# v1.2.8.0, Doc Pushes Fix Their Own Gaps

v1.2.7.0 named the divider gap and offered the fix. Every doc page push now runs the fix itself, after checking how ClickUp imported the markdown.

## What's New at a Glance

- **The import is checked.** A line that ClickUp dropped, escaped or turned into a heading is caught before the push is reported
- **The gaps are removed.** The routine in the vendored `mcp-click-up` packet deletes the empty line under each divider in the ClickUp editor and proves the text is unchanged
- **Done means clean.** A push is reported done only when both checks pass, and a ClickUp login prompt turns into one request to log in

## Changed

- `SKILL.md` Section 7 Push Targets: the offer bullet became two bullets that run the routine and set when a push counts as done
- `AGENTS.md` ClickUp Handoff: one sentence states the same rule

## Upgrade

No Project file changes. The kernel stays at v1.2.16, because the claude.ai connector was not checked for the gap and a Project has no browser to run the routine.
