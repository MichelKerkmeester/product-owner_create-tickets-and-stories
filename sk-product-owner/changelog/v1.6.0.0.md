# v1.6.0.0, Canonical Routing and Sole Authority

This is the smart-routing parity release. Section 2 now carries the canonical five subsections in a fixed order. An executable route contract characterizes routing without invoking a model. `Custom Instructions.md` becomes the sole routing authority in the claude.ai Project, because the SKILL mirror no longer ships there.

The route object gained `shape` and `on_demand`, so it carries eight fields rather than the six the release record describes. The fixture manifest has grown past a hundred entries. The paragraphs below keep that record as written. `benchmark/router/README.md` carries the current shape.

## Why This Release

Product Owner joins the fleet-wide routing hardening.

No artifact intent, command token, framing rule, confidence threshold or Doc/Story delivery contract changed.

## What's New at a Glance

- **Section 2 carries the canonical five subsections in a fixed order.** Primary Detection Signal and Resource Domains are new. Detection Sequence is now Phase Detection with its nine steps unchanged.
- **The executable oracle must never drift from Section 2.** A sentence under the `## 2. SMART ROUTING` header says so. Confidence Thresholds and Smart Router Pseudocode already matched the exact-token and word-boundary contract, so their behavior did not change.
- **An executable contract characterizes routing without invoking a model.** Exact `$token` detection, word-boundary keyword scoring with the same 0.85 documentation/story confidence override as the skill, artifact-framing patterns and confidence gates build the route, with Standard at 0.60 or above, Quick at 0.40 or above and Task as the fallback.
- **The route object carries eight fields.** It gained `shape` and `on_demand` beyond the six fields named in the release record. `benchmark/router/README.md` carries the current shape.
- **Fixtures cover commands, framing, conflicts and adversarial input.** The set includes every dollar-command, natural-language framing, command precedence, a two-command conflict and the 0.40 versus 0.60 energy split. A `bug` inside `debugging` and a `$doc` inside `$document` both route to Interactive Mode.
- **Custom Instructions is the sole routing authority in the Project.** Section 2 repeats the five subsections as advice, because a Project cannot execute the contract. Section 3 holds 15 ALWAYS items, 15 NEVER items and the ESCALATE IF rules.
- **No rule was dropped in the rebuild.** The Critical Rules list, the Refusal and Clarification section and the standalone Escalation section folded into the new structure. Tie-breaks sit in Phase Detection and the Doc Shapes and Source Contract section now holds the ClickUp And Story Formatting Contract.
- **The SKILL mirror no longer ships in Project Knowledge.** The skill stays in `contractInputs` and is no longer uploaded. `expectedKnowledgeCount` moved from 32 to 31.

## The Executable Route Contract

#### The Written Record And The Live Shape

`benchmark/router/` is new. The release record describes a route object with six fields: `intent`, `energy`, `source`, `confidence`, `needs_disambiguation` and `resources`. It also describes 23 fixtures. The object gained `shape` and `on_demand`, so it carries eight fields. The fixture manifest has grown past a hundred entries. `benchmark/router/README.md` carries the current shape.

&nbsp;

#### How The Contract Chooses A Route

The contract builds a route from exact `$token` detection, word-boundary keyword scoring with the same 0.85 documentation/story confidence override as the skill, artifact-framing patterns and confidence-gated directness. Standard routes at 0.60 or above. Quick routes at 0.40 or above. Otherwise the route falls back to Task.

&nbsp;

#### Field Checks And Safe Loads

The contract rejects unknown, missing or duplicate fields and invalid enum values. Resource resolution discovers the live `references/*.md` and `assets/*.md` inventory at every call. A renamed or deleted reference degrades instead of crashing. The shared Human Voice Rules symlink resolves correctly.

&nbsp;

#### The Cases The Fixtures Hold

The fixture set covers every dollar-command, including `$task --subtask`. It covers natural-language framing per artifact, a case where `$doc` beats a `bug report` framing collision, a two-command conflict and the Quick-energy 0.40 versus Standard 0.60 threshold divergence.

The word `bug` must not match inside `debugging`. The exact token `$doc` must not match inside `$document`. Both adversarial inputs route to Interactive Mode.

## Custom Instructions

#### The Project Carries The Same Routes

`Custom Instructions.md` moves from v1.4.0 to v1.5.0 and is aligned to Skill 1.6.0. It was rebuilt in full. Section 2 carries the same five routing subsections as the skill, adapted as advice. The Smart Router Pseudocode subsection restates the oracle's decision order as numbered prose instead of code, because a Project cannot execute it.

&nbsp;

#### Always, Never And Escalate

A new Section 3 Rules carries the skill's full ALWAYS list (15 items), NEVER list (15 items) and ESCALATE IF rules. The NEVER list includes an advisory-truthfulness item that bars any claim of local execution. The rules are adapted for a Project that cannot write files or call ClickUp without the connector.

&nbsp;

#### Nothing From The Old Rules Was Lost

The prior Critical Rules numbered list, the Refusal and Clarification section and the standalone Escalation section were consolidated into this structure. No rule was dropped. Routing tie-breaks moved into Phase Detection. Source-authority ordering and Doc Shapes detail moved into a rebuilt Doc Shapes and Source Contract section, now with an explicit ClickUp And Story Formatting Contract subsection. Every remaining item landed in ALWAYS, NEVER or ESCALATE IF.

&nbsp;

#### The Rest Of The Document Stayed

Operating Model, Doc Shapes, Quality Gate, Smart Routing Matrix, Project Knowledge Consultation, Delivery Protocol and Quality Checklist all carried forward with their existing domain content intact. They were renumbered to fit the new section order.
