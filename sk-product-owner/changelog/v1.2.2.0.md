# v1.2.2.0, README Matches the Skill

A claim-by-claim check of `README.md` against the packet found descriptions that had drifted from the templates and the tree. The skill's rules, templates, router and examples are unchanged, so the release moves one patch step and the kernel needs no edit.

## What's New at a Glance

- **The sibling packet.** The README names `../sk-create-figjam/` as the home of every diagram drawn on a FigJam board, not user flows alone
- **The example count.** `assets/` holds 21 worked examples, not 20
- **The bug shape.** The bug report section now shows the template as it is: where the bug occurs and its field table, then Observed Behavior with its steps to reproduce, then Expected Behavior with the four-item checklist
- **The Story headings.** A Story's Problem and Solution sit at H2, and an Epic's Problem, Goal and Solution sit at H4 under its About

## Upgrade

No migration required. The claude.ai Project needs no new Knowledge file and no kernel change.
