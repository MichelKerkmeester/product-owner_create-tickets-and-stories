# v1.2.13.0, Numbered Task Titles Escape Their Full Stop

ClickUp read each `1.  **{Title}**` line as a numbered list of one item. The divider after the title ends that list, so every title on a pushed page read `1.`.

## What's New at a Glance

- **The template writes `1\. **{Title}**`.** Task Templates and the three Task Mode patterns use the escaped form, and the rule says why
- **The examples match.** The Standard Feature, Subtask and UI Refinement examples and the README use the same form
- **ClickUp keeps the number.** A live push on 2026-11-10 showed the escaped form as a plain paragraph that reads back exactly as sent

## Upgrade

The five task Knowledge files carry the same change. Upload them to the Project again. A task written before this release can be fixed with the same edit before a push.
