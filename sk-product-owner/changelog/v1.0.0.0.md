# v1.0.0.0, Skill Becomes the Runtime Source

This is the founding release of Product Owner. It received its first split between a `skill/` folder and a `claude project/` folder in the system-wide packaging migration. Product Owner received `skill/SKILL.md` at version 1.0.0 beside the legacy identity file `Product Owner - System - Prompt - v0.997.md`. That skill file would replace the identity file five days later.

The `skill/` folder is the source of truth and the CLI runtime identity. You enter it through an `AGENTS.md` bootstrap. The `claude project/` folder carries a hand-synthesized kernel and knowledge mirrors for claude.ai.

Product Owner lived at the repository root already. The flatten that moved other systems did not move it.

## Why This Release

The system-wide packaging migration gave every Barter AI system the same split. The `skill/` folder is the source of truth and the CLI runtime identity. The `claude project/` folder carries a hand-synthesized kernel and knowledge mirrors for claude.ai.

Product Owner lived at the repository root already, so the flatten that moved other systems did not move it. This commit pinned `skill/SKILL.md` at version 1.0.0, read directly from the historical frontmatter. Later releases in this changelog build on that pin.
