# v1.1.0.0, Skill File Becomes the Sole Identity

This release makes `skill/SKILL.md` the sole skill identity for Product Owner and pins that skill at 1.1.0 for the whole span of the entry. The same pin covers the first split between `skill/` and `claude project/`, the birth of the skill file and a later Claude Project kernel at v1.0.0. Later steps did not change the pinned 1.1.0 skill version. The version next moves in the 1.4.0.0 release.

Packaging began on 2026-06-10. On 2026-06-15 the flatten-layout commits deleted the Prompt file, made SKILL.md the sole identity and bumped it to 1.1.0. The Human Voice Rules were re-frozen the same day. On 2026-07-13 `claude project/Custom Instructions.md` reached v1.0.0.

## Why This Release

`skill/SKILL.md` was already pinned at 1.0.0 beside the legacy prompt file `Product Owner - System - Prompt - v0.997.md`. Product Owner's dual-runtime packaging began five days earlier on 2026-06-10 and gave Product Owner its first `skill/` plus `claude project/` split. Dual-runtime means a split between the `skill/` folder and the `claude project/` folder.

On 2026-06-15 the flatten-layout commits deleted the Prompt file, made SKILL.md the sole identity and bumped it to 1.1.0.

Task, Bug and Interactive were the only intents. Doc and Story did not exist yet.

## What's New at a Glance

- **Packaging splits the skill from the Claude project.** Product Owner gained its first split between `skill/` and `claude project/`.
- **The CLI wrapper and the project files arrived.** `AGENTS.md` became the CLI bootstrap and enforcement wrapper. `SYNC.md`, `claude project/Custom Instructions.md` and `claude project/README.md` arrived, with the README as the upload manifest.
- **Stale product context left the package.** The packaging removed old App Store descriptions, superseded DS Variables exports and retired Feed v2 and v3 documentation.
- **SKILL.md replaces the prompt file.** The flatten step deleted the prompt file and created `skill/SKILL.md` at version 1.1.0. That file is the first single-brain skill file for Product Owner and it replaces the older prompt-file concept.
- **Templates become their own assets.** The step split `skill/assets/task_templates.md`, `skill/assets/bug_report_template.md` and `skill/assets/interactive_response_templates.md` out of the mode references.
- **Three modes move up to match the dedicated assets.** The step bumped Interactive Mode to v0.402, Bug Mode to v0.201 and Task Mode to v0.301 to match the templates split out of the mode references.
- **References open with an overview.** The pass put `## 1. OVERVIEW` at the top of every real skill reference and asset.
- **Human Voice Rules keep their scores.** The English and Dutch rules moved to the sk-doc reference template and the shared scoring baseline was re-frozen. Banned-word, blocker and deduction content stayed byte-unchanged.
- **The Claude Project kernel reaches v1.0.0.** `claude project/Custom Instructions.md` moved from v0.998 to v1.0.0 while `skill/SKILL.md` stayed at 1.1.0.
- **The upload list becomes a checksum table.** `claude project/README.md` now uses a Paired-Version + Checksum Table that lists each knowledge mirror's version and sha256-16 checksum.

## Dual-Runtime Packaging

#### Product Owner Gains a Runtime Split

On 2026-06-10 Product Owner received its first split between `skill/` and `claude project/`. `AGENTS.md` became the CLI bootstrap and enforcement wrapper. The packaging created `SYNC.md` and `claude project/Custom Instructions.md`. `claude project/README.md` landed as the upload manifest.

&nbsp;

#### The Prompt File Still Held the CLI

At the split, the CLI identity file was still `Product Owner - System - Prompt - v0.997.md`. It was paired with Interactive Mode v0.401, Bug Mode v0.200, Task Mode v0.300, DEPTH Framework v0.201 and Human Voice Rules EN v0.210.

&nbsp;

#### Stale Product Context Comes Out

The same packaging removed a large block of stale product context that had accumulated ahead of a full-service migration. The removed material is old App Store descriptions, superseded DS Variables exports and retired Feed v2 and v3 documentation.

---

## Skill Identity

#### SKILL.md Becomes the Only Identity

On 2026-06-15 the flatten step deleted `Product Owner - System - Prompt - v0.997.md`. The deletion names that file `System - Prompt - v0.997.md`. The same step created `skill/SKILL.md` at version 1.1.0.

This is the first single-brain skill file for Product Owner. It replaces the older prompt-file concept, so one skill file is the identity.

&nbsp;

#### Templates Leave the Mode References

The same step split three template files out of the mode references into dedicated assets for the first time, `skill/assets/task_templates.md`, `skill/assets/bug_report_template.md` and `skill/assets/interactive_response_templates.md`, and bumped Interactive Mode to v0.402, Bug Mode to v0.201 and Task Mode to v0.301 to match.

&nbsp;

#### Overviews Sit at the Top

The same pass put `## 1. OVERVIEW` at the top of every real skill reference and asset. Each of those files now opens on that heading.

---

## Human Voice Rules

#### Scoring Stays While the Shape Changes

A same-day follow-up converted the English and Dutch Human Voice Rules to the sk-doc reference template. That template is five-field frontmatter, a one to two sentence intro and `## 1. OVERVIEW`. The follow-up re-froze the shared scoring baseline.

The HVR checksum moved from `3f092d99b55b` to `f8980baed64d`. The banned-word, blocker and deduction content stayed byte-unchanged, so the re-freeze touched structure and cross-reference numbering, not scoring rules.

---

## Claude Project Kernel

#### Custom Instructions Reaches v1.0.0

On 2026-07-13 a system-wide standardization bumped `claude project/Custom Instructions.md` from v0.998 to v1.0.0. `skill/SKILL.md` stayed pinned at 1.1.0.

&nbsp;

#### The Upload List Becomes a Checksum Table

The same step rebuilt `claude project/README.md` around a new Paired-Version + Checksum Table. The table lists each knowledge mirror's version and sha256-16 checksum in one place. It replaces the plain `## Upload` list the file used before.

That table shape is the direct ancestor of the thirty-row inventory the 1.4.0.0 release later expands to cover Doc and Story mirrors.

## Upgrade Notes

- **Adopt.** Use `skill/SKILL.md` at version 1.1.0 as the sole identity. Use Interactive Mode v0.402, Bug Mode v0.201 and Task Mode v0.301. Use `SYNC.md`, `claude project/Custom Instructions.md` at v1.0.0 and the Paired-Version + Checksum Table in `claude project/README.md`.
- **Repoint.** Read templates from `skill/assets/task_templates.md`, `skill/assets/bug_report_template.md` and `skill/assets/interactive_response_templates.md`.
- **Drop.** Do not use the prompt file `Product Owner - System - Prompt - v0.997.md` or `System - Prompt - v0.997.md`. Old App Store descriptions, superseded DS Variables exports and retired Feed v2 and v3 documentation are removed.
