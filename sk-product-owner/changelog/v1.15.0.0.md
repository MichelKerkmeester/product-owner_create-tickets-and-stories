# v1.15.0.0, Artifacts Now Have Word Budgets

This release sets artifact word budgets for every kind, counted outside code blocks. The budgets bound the whole artifact, where the length caps bound only a line.

## Why This Release

The length caps bound a line, never a whole artifact. The Opus 5.5 benchmark exports met the caps after a first edit and still read long, because that edit split lines and cut 2% of the words. A second edit cut their words by 22.7% with every supplied value kept, and the budget is taken from those cut exports.

## What's New at a Glance

- **Artifact word budgets cover every kind.** A task inside a Story bundle is at most 500 words, a subtask 750, any other task 900, a bug 800, an Epic 1,000 and a Story or a Doc 1,400. The words are counted outside code blocks.
- **An artifact goes over its budget only for supplied content.** It does so only when supplied values, requirements or criteria need the room, never with restated context or background.
- **The Conciseness line names the budget after the caps.** `SKILL.md` and the kernel both name it there. The shared Conciseness card is unchanged.
- **The playbook root names the budget in its Advisory size row.** A miss is reported and never fails a scenario.
- **The kernel moves from v1.17.0 to v1.18.0.** Its review by the operator is pending.
- **No line the playbook cites moved.** Every edit stayed on its own line.

No migration required.
