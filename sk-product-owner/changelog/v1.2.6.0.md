# v1.2.6.0, Complete Sources Still Get the Question

`SKILL.md` already said an explicit command asks its mode's question "however much context the request carries". The Story question template also said "Populate only unresolved fields", and a model reading both decided the question collapses to nothing when the sources answer every field. It then drafted on turn 1. This release removes that reading.

## What's New at a Glance

- **The question always has a field left to ask.** Its Validation field is never settled by the sources, so the question an explicit command asks always carries it and waits

## Changed

- `SKILL.md` Clarification Protocol: an explicit command's question carries its Validation field and waits, however complete the sources look
- `assets/interactive-response-templates.md` Story Context Question and Doc Context and Clarification Question: the Validation field always stays (0.17.0.12)
- `references/story-mode.md` Interactive behavior and Step 1: an explicit command asks and waits even when the sources settle every field (0.17.0.30)
