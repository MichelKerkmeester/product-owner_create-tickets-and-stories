# v0.9.0.0, Two Table Rules and a Worked Example

Task Mode gains two table rules and a worked example from a shipped Barter design token release. A ticket table carries at most 4 columns and a table of per-size values leads with Size in the leftmost column. The example shows both rules on a parent task with one subtask per app, in the ClickUp format the team ships.

## What's New at a Glance

- **A ticket table carries at most 4 columns.** Past that limit it splits into more tables that repeat the first column. `references/task-mode.md` adds the rule in a Tables subsection under Structure Rules, keeps file version v0.303 and adds the matching Structure Validation checklist line.
- **A per-size table leads with Size.** In that same Tables subsection, a table of values that vary by size puts Size in the leftmost column, with one row per size and one column per token or property.
- **The worked example comes from a real product.** `assets/examples/task/task-example-ds-variables.md` at v0.100 holds the parent task `DS - Variables - v1.0.7 - Size Variables & Disabled States` with Partner and Creator subtasks, one per app, as shipped to ClickUp. It shows both rules and is the one example in the library on a real product.
- **Task Templates points at the example.** `assets/task-templates.md` points at it from Parent Task and from Subtask. Live attachment links in the example are `clickup-attachment-url` placeholders.
- **Export errors were corrected rather than taught.** A parent About no longer contradicts its own rename table and the Creator About and requirement title are no longer copied from Partner. Token names keep a leading dash, an empty table cell was corrected and rem values are no longer spaced.
- **The skill README counts 21 examples.** `sk-product-owner/README.md` adds an examples table row and moves the example count from 20 to 21.
- **Custom Instructions and the project README show the new versions.** `claude project/Custom Instructions.md` moves its H1 from v0.12.4 to v0.13.0 and keeps the same kernel statement. `claude project/README.md` updates its kernel and skill version claims and its upload count from thirty-seven to thirty-eight.
- **Project knowledge adds the example.** `claude project/knowledge/` updates the Task Mode and Task Templates mirrors and adds the new `Product Owner - Examples - Task - DS Variables - v0.100.md`.
