# v1.2.17.0, Scaffolds, Spacers and the Feedback Path

A fresh review found scaffolds that taught what the gate blocks. This release fixes them and the drift beside them.

## What's New at a Glance

- **Doc scaffolds pass the gate.** Six em dashes and three semicolons are gone from the scaffolds
- **Spacers stay in a Doc export.** The Doc rule now matches the Story rule and the 42 spacers in the examples
- **The feedback path uses slugs.** The kind is `logic` or `ui-ux`. The feature and app hold no slash, dot or space
- **One ticket, one kind.** The feedback example no longer mixes a Logic item into a UI/UX ticket
- **The Flow reply is stated once.** The skill points at Flow Mode Section 8 and keeps three facts
- **Mark-as-done is stated once.** Story Mode Section 3 keeps the full divider rule. Other files point at it
- **Feedback tickets are listed.** The Task Mode When To Use list names them. Rule 9 carries the Open items clause

## Changed

- The README counts sixty-seven Project documents and five task shapes
- Rule 3 points at the packet `ROUTER.md` Section 3
- The skill-side Doc playbook scenarios no longer grade spacer headings
