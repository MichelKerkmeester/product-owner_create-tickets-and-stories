# v1.2.19.0, a Designed Screen's Copy Stays in the Design

A Story for a new screen listed every badge, heading, subheading and button label as its own requirement. The rules asked for it, because copy a design shows counted as a supplied value. That changes here.

## What's New at a Glance

- **One pointer per designed screen.** A new screen or component supplied as a Figma frame, a design link or a screenshot gets one item saying its copy and layout follow the design
- **Only what a design cannot show.** The other items hold an order, a condition, a navigation target, a state, a platform or a reuse entry
- **No item per visible string.** A badge, a heading and a button label on a designed screen get no items of their own
- **A string is quoted inside a rule.** It names the element, as in `For Creators` comes before `For Partners`
- **Typed values still travel verbatim.** So does a shown string that is itself the change, such as replaced copy

## Changed

- Story Mode's verbatim rule binds typed strings and changed strings, and no longer every string a design shows
- A screen's group no longer counts a designed screen's visible strings as supplied values
- The Story template strikes an item that only quotes a string a design already shows
