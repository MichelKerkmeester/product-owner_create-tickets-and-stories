# Product Owner - Local - Push Targets

The ClickUp lists and docs this Product Owner pushes to, each under its own name. Keep one filled copy at `claude project/local/Product Owner - Local - Push Targets.md`, where the skill reads it, and upload that same copy to your own Project only. It is never part of the shared Knowledge set, and it is consulted before every ClickUp offer.

Add one line per list or doc, its name and then the link copied from ClickUp, under the team that owns it. The name and the team are what an artifact is matched against, so name each one the way your team says it. A section with no lines is fine.

## Lists

Tasks, subtasks, parent tasks, bugs, Stories and Epics are created in a list.

### Team name

- **List name:** list link

## Docs

A document is added as a new page inside the doc that fits it.

### Team name

- **Doc name:** doc link

When one list or doc fits, the offer names it. When more than one could fit, the offer names them and asks which. When none fits, or this file is absent, the offer asks where and recommends a private doc. Every push still waits for your yes in the chat.
