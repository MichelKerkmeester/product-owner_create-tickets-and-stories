# v1.0.10.0, The First State Leads

Claude Sonnet 5.5 high reran on v1.0.9.0 the 7 FigJam scenarios that had failed and passed 1, with Composition at 0 on every scored board. `sk-create-figjam` v1.0.10.0 fixes both causes.

## What's New at a Glance

- **The first state leads.** The composer lays an edge into or out of a composite against its inner start, so an early label line no longer pulls the composite ahead of the first state
- **Plans follow the path.** A flow's glance lines name every node, the main row in path order
- **A revision's whole main row waits.** The revision exemption covers every main-row node planned last
