# v1.0.24.0, ClickUp Pushes Check the Logins First

A first ClickUp push now finds a missing approval or browser login before it writes, and asks the user to fix it.

## What's New at a Glance

- **The push checks the logins first.** `sk-product-owner` v1.2.12.0 runs the readiness check after the push is approved
- **The vendored ClickUp packet carries the check.** `mcp-click-up` v1.2.14.0 holds the program and the questions
- **The gap pass can run from this repository.** `.utcp_config.json` gains the `aside` and `chrome_devtools_live` manuals, so a clone of Product Owner alone can remove the divider gaps

## Changed

- `sk-product-owner` moves to v1.2.12.0, as its own note lists
- `AGENTS.md` names the check in the ClickUp handoff and cites `mcp-click-up/SKILL.md` Section 1, where it cited a Section 0 that no longer exists
- The README's version row and release links name this release

No Project file changes. The kernel stays at v1.2.17.
