# v1.0.6.0, One Question First and Boards That Read in Greyscale

Claude Sonnet 5.5 high ran all 54 FigJam scenarios on v1.0.5.0. After an Opus grader, skeptics and an adjudicator had checked the grades, the run stood at 23 PASS, 29 FAIL and 2 SKIP. `sk-create-figjam` v1.0.6.0 and `sk-product-owner` v1.2.3.0 fix the skill rules and the composer behind those findings, and the playbook, the test driver and the run's records changed with them.

## What's New at a Glance

- **The type question goes alone.** When two diagram types fit, or the type you named does not fit the brief, the first reply asks only that, before any other question
- **One board means one board.** Ask for one board and an oversized diagram loses its least-needed part, named on the `Left out:` line, with the split offered as the alternative
- **Boards read in greyscale.** Kinds that share a shape now differ by outline as well as colour, and the key names a plain connector `Leads to`
- **The key can say why.** A focus line with a reason puts that reason in the key as `In focus: <reason>`
- **A board command asks about the artifact first.** When `$task` and `$flow` conflict, the first question settles the artifact and asks no board fact
- **A kept term is counted only when it is the banned pattern.** The Human Voice Core card, shared with four other systems, no longer counts a literal use of a kept term on the self-scan line

## Changed

- The comparison's driver sends a scenario's own scripted answer straight after an intake reply, and sends the generic recommended answer only once the script has no answer left, and past the script's end only in a scenario that expects a board
- A `driver:` frontmatter key marks a scenario `operator-only`, which a model run skips, or `new-file`, which runs with no file pin. FJ-018, FJ-035, FJ-044 and FJ-045 are operator-only and FJ-008, FJ-017 and FJ-019 run on a new file
- The driver runs each scenario's read-only `Commands` steps in its sandbox after the model finishes and records them in `commands.json`
- The Sonnet 5.5 high grades carry every adjudication, the run folder holds its renders, checks and reader notes, `results.jsonl` holds its 54 rows and the run README gains section 8.5
- The README and the user guide say the type question comes alone, one board is cut rather than split and the pink outline is the heaviest line on a board
