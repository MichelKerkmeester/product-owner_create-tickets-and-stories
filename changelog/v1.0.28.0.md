# v1.0.28.0, Review Fixes for the ClickUp Page Writer and Format Gate

A deep review of the last release found 15 issues. This release fixes all of them.

## What's New at a Glance

- **Uploads read only image files.** `mcp-click-up` v1.2.20.0 refuses a path or a non-image file
- **Script links stay plain text.** Only http, https and mailto links keep a target
- **The push check knows what to expect.** It compares dividers, gray runs, checklist items and columns with the source
- **The gate's fixer places every divider.** `--write` now handles any number of Mark-as-done lines
- **Fixtures say one thing each.** The checkbox near-miss has its own passing fixture. Both harnesses assert the same cases

## Changed

- `sk-product-owner` moves to v1.2.16.0
- `vendor.json` pins `mcp-click-up` at the new upstream commit
- Both format validators and both fixture corpora
- Packet 027 and 028 evidence, `SYNC.md` and the skill README version and example count

## Upgrade

No Claude Project upload. The kernel and knowledge files did not change.
