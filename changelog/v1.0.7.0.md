# v1.0.7.0, One Board Is What the Words Say

Claude Sonnet 5.5 high reran on v1.0.6.0 the 31 scenarios v1.0.5.0 did not pass and passed 14 of the 27 it ran, with 13 failing and 4 operator-only scenarios left out. A findings pass and a critic named 35 findings. `sk-create-figjam` v1.0.7.0 and `sk-product-owner` v1.2.4.0 fix the skill rules and the composer behind them, and the playbook, the test driver and the run's records changed with them.

## What's New at a Glance

- **One board is what the words say.** A request for one board says one board, a single board or one diagram, and naming where the board goes is a destination, so an oversized flow splits as before
- **A missing route still plays back first.** With no Figma route the intake and the playback run as usual and the gate names the missing route, in the skill and in the Project kernel
- **A leadership reader sets the dials.** A leadership reader sets the Executive audience and the Simplified detail level, and the gate names all three dial settings
- **The checks catch three more slips.** A node that returns to itself, a state guard that names an id and arrivals closer than 24 pixels on one side of a node
- **A board command conflict asks about the artifact alone.** Its Open items name no board fact either

## Changed

- The comparison's driver tells a pinned run that the test file is in the plan its prompt names, and tells a new-file run which real plan to use, set at launch, in drafts, with no project, so no run gets two destinations. A prompt that names no plan gets no plan sentence
- The driver can hold a run before a scripted turn while the operator does their own step, records how many sections the file held before turn 1, fills a prepared board's file key into its prompt and runs an operator-only scenario once the operator has done its setup. A bad setting stops the run before its first turn, and a script with no playback answer sends its own next turn after an intake reply
- The v1.0.6.0 rerun records carry the critic's corrections: Reply 1 on FJ-029 and FJ-032 for a visual read no screenshot backs, the scorecard signal on all eight board records that lacked it, FJ-035 split into its nine signals and the four operator-only scenarios recorded as not run. The gallery FJ-023 scores Fidelity 2 against its own model under the new Fidelity row, 20 of 22, and still fails
- The README's version row and release links name this release
