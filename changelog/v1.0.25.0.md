# v1.0.25.0, Numbered Task Titles Stay Plain Numbers in ClickUp

A task pushed to a ClickUp doc showed every requirement title as `1.`, literal checkbox brackets and divider gaps the gap pass had reported as gone.

## What's New at a Glance

- **Task titles keep their numbers.** `sk-product-owner` v1.2.13.0 writes each numbered requirement title as `1\. **{Title}**`
- **The vendored ClickUp packet fixes the push.** `mcp-click-up` v1.2.17.0 finds the page body in the gap pass and sends an empty checkbox as `- [ ]`

## Changed

- `sk-product-owner` moves to v1.2.13.0, as its own note lists
- The README's version row and release links name this release

## Upgrade

The five task Knowledge files changed in the same words as their sources. Upload them to the Project again. The kernel stays at v1.2.17.
