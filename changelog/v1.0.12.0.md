# v1.0.12.0, Gate Sides and Goal Names

The v1.0.11.0 rerun passed 2 of the 4 FigJam scenarios it reran and named a set of findings. `sk-create-figjam` v1.0.12.0 fixes them, and Flow Mode's stops now end on their question.

## What's New at a Glance

- **The gate sees each note's side.** A `%% notes:` line and the check's `Sides:` lines tell the gate where each sticky will land before any write
- **The goal is named, not accented.** A `%% goal:` line names the goal, and the one accent goes to a decision, a failure end or the step in focus
- **A stop ends on its question.** An intake round, the playback and the gate carry no self-scan line after their question

## Changed

- `AGENTS.md` says a Flow Mode stop delivers nothing, so it ends on its question with no self-scan line
- The Project kernel moves to v1.2.12: its Flow gate shows the checked sketch and the four critique answers
- The README's version row and release links name this release
