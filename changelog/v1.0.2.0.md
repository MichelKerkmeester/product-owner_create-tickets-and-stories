# v1.0.2.0, A Front Page for FigJam and Fixed Tool Packets

The README read like a maintainer's notebook: fixture counts, guard lists and route objects came before what the system does, and FigJam boards sat in the middle of a long list. The user guide was an install guide. Both now start with what a person asks for and what comes back, and the maintainer detail lives in the benchmark READMEs where it already was.

## What's New at a Glance

- **A product README.** `README.md` keeps its house template and gets new copy: FigJam leads the What's inside list and has its own section with a composed board, and the checks section is now the gate command and a table of where the detail lives, with no fixture counts. It went from 961 to 650 lines
- **FigJam in front.** A FigJam section names the seven diagram types by the question each one answers, shows a composed board and walks from request to board in six steps. `sk-create-figjam` v1.0.2.0 adds a gallery of nine real boards
- **A user guide for daily use.** `USER-GUIDE.md` covers asking for an artifact, drawing a board, steering the result, sending it to ClickUp and connecting ClickUp and Figma, with troubleshooting last. Its Knowledge mirror, Reference - Connector Setup, takes the setup changes
- **Fixed tool packets.** The vendored packets come in from upstream: `mcp-click-up` v1.2.4.0, whose examples no longer report success when cupt fails or the token is bad, `mcp-figma` v1.1.5.0, whose examples write failures to stderr, and `mcp-code-mode` v1.0.12.0 with the launcher and engine resolver beside it. All three name packet-relative paths, so their scripts work in this vendored copy

## Changed

- `sk-product-owner` moves to v1.2.2.0 for its README corrections and `sk-create-figjam` to v1.0.2.0 for the gallery and the second-glance rubric fix
- The scripts under `scripts/` and `benchmark/` carry file headers, numbered sections, docstrings and type hints. No output changed, and every gate still passes
- The benchmark and scripts READMEs state the counts the checks run today: 188 router fixtures, 281 differential inputs on nine guards, 51 hub gold rows and 52 FigJam scenarios. `benchmark/reports/README.md` indexes every run folder
- The Sync Loop declaration records the composer review and declares the screenshots README as deliberately unmirrored

In the claude.ai Project, replace Reference - Connector Setup. Nothing else on the Project side changed for the hub.
