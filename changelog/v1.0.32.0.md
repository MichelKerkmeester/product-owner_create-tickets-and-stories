# v1.0.32.0, the Format Gate Advises on a Title

The title rule shipped with no check behind it. The gate now reads the title of a backlog artifact.

## What's New at a Glance

- **Four things are reported.** A sentence title, a closing full stop, a leading date and a `BUG` lead
- **It advises, never blocks.** A refinement keeps its source title. A title the requester states is used as given
- **One line per title.** The first rule that applies is named
- **Docs are left alone.** Only an artifact that opens on `## About` or `## Problem` is read
- **The shared validator matches.** The Sync Loop core prints the same lines for this system and none for the others
- **The playbook reads true.** Twelve scenario overviews now say the title rule asks for the team lead
- **The grader README has the README shape.** Its nine headings are upper case

## Changed

- `benchmark/format/` gains three fixtures and eight fixture cases
- The vendored `mcp-figma` copy is at v1.2.3.0
- `sk-product-owner` and the Project kernel do not move

## Upgrade

No Claude Project change. The gate runs in the repository, not in a Project.
