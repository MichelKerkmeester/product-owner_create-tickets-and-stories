# v1.0.36.0, Story Criteria and Checklist Layout

The house Story layout changes in four places. New Stories and Epics now use it, and the format gate checks it.

## What's New at a Glance

- **No divider under Mark as done.** One empty line leads to the next criterion, and the last criterion ends the artifact
- **A Checklist label per section.** A numbered requirement section sets its checks under a bold `**Checklist**` label with a divider
- **User flows as steps.** `**User flow:**` stands alone, with one bullet per step
- **Screenshots in columns.** A push sets a section's screenshots side by side

## Changed

- `sk-product-owner` moves to v1.2.20.0, as its own notes list
- Both format validators enforce the new layout and stay output-identical
- The Project kernel moves to v1.2.22
