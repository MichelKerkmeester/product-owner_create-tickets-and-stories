# v1.0.8.0, Plan What the Board Shows

Claude Sonnet 5.5 high reran on v1.0.7.0 every FigJam scenario that had not passed and passed 2 of the 16 it ran. Composition was the largest cause, because the glance rules and the shipped examples planned a different first read than the board gives. `sk-create-figjam` v1.0.8.0 fixes the rules and the examples and adds a label warning to the pre-write check, and the playbook and the run's records changed with them.

## What's New at a Glance

- **Glance plans match the board.** A state board plans its first state first and reads its composite as frame. The light blue entry joins the kinds that read right after the accent. The process, architecture, user flow and state examples plan what they draw
- **What the board leaves out is always named.** The reply and the gate carry a `Left out:` line for every cut, split, later board or point the sources left open, in the skill, the Project kernel, `AGENTS.md`, `sk-product-owner` and the user guide, and every shipped example's gate shows it
- **A sticky finds its place.** It goes past its node's end dot, takes the shortest clear side when every side is taken and is never moved without a new yes
- **A label warning before the gate.** The pre-write check names a label the board would wrap with one word alone on its last line, so the model can shorten it. The composer is unchanged, so the Project keeps its room

## Changed

- `AGENTS.md` and the kernel describe the `Left out:` line the same way the skill does
- The v1.0.7.0 rerun records follow the playbook's scope: FJ-017, a board-write scenario, carries no scorecard and fails on its own signals
- `sk-product-owner` v1.2.5.0 states the same `Left out:` rule for the Flow route
- The README's version row and release links name this release
