# v1.0.3.0, A Board Design Your Team Owns

A team could not change how its FigJam boards look without editing the composer's code, and the seven diagram types had drifted apart in small ways a reader notices across boards. `sk-create-figjam` v1.0.3.0 moves the look into one design file and draws every type from it.

## What's New at a Glance

- **One design file.** `sk-create-figjam/assets/figjam-design.md` says which FigJam colour means what, which pair carries the first glance, the type sizes, the lines, the zone tints and the words on the key. Edit it once and every board composed after it follows
- **Safe edits.** A token that would weaken contrast or compete with the first glance falls back to its shipped value, and the reply names it on a `Finding:` line, so a bad edit never stops a board
- **One family.** The key, the connector colours, the zone tints and the type sizes now match across all seven diagram types, and sequence participants are white
- **The Project follows.** The claude.ai Project gains Assets - Flow Board Design, which carries the `THEME` line its composer takes, and kernel v1.2.4 names it in the Flow consultation set and the composed write

## Changed

- `leaf-manifest.json` lists the design file, and the README and user guide say how to change the look of every board
- The README leads with tasks, bug reports, Stories, Epics and Docs again. FigJam boards follow as their own section after delivery, and the What's inside list closes on two FigJam lines
- The Project README counts 65 Knowledge files and gives the composer's new size: 1,161 lines and 46,569 characters, with about 3,400 characters left for the model and the `THEME` line
- The Sync Loop declaration pairs the design file with its Knowledge mirror and drops the composer review record, because the composer and its mirror changed together. It records a review of the user guide's change instead, whose new bullets sit in usage sections its Knowledge mirror does not carry

## Upgrade

In the claude.ai Project, upload Assets - Flow Board Design, replace the Flow Knowledge files the `sk-create-figjam` v1.0.3.0 notes list and paste kernel v1.2.4.
