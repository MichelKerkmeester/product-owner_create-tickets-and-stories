# v1.0.37.0, Design Copy Stays in the Design

A Story built from screenshots no longer lists their buttons, headings and toasts in backticks. New Stories and Epics follow the rule, and the format gate advises when one does not.

## What's New at a Glance

- **Typed copy travels, screen copy stays.** Text the requester types is kept verbatim, and text read off a screenshot or design stays in the design
- **One string can still be quoted.** The string the requester says is the change is quoted once
- **Elements by role.** Requirements and Given/When/Then lines name the primary action or the confirmation toast, never its label
- **A gate advisory.** A Story quoting twelve or more distinct UI strings draws one advisory, and it never blocks

## Changed

- `sk-product-owner` moves to v1.2.21.0, as its own notes list
- Both format validators carry the advisory and stay output-identical
- The Project kernel moves to v1.2.23
