# v1.0.15.0, Reading Order and Reply Lead

The v1.0.14.0 rerun of the 4 FigJam scenarios named a set of findings. `sk-create-figjam` v1.0.15.0 fixes them.

## What's New at a Glance

- **A FigJam plan reads the accent first and then column by column.** The lift that put a decision beside the accent second is gone, because readers did not take it
- **Every delivery reply opens on the board URL.** No sentence comes before it, not even one that says the board is written or that the reply follows
- **Diamond labels are measured by glyph width.** The check wraps a decision's label the way FigJam does, so it flags a stranded last word that a character count passed

## Changed

- The Project kernel moves to v1.2.15: its Flow reply opens on the board URL as the first characters of the message sent after the last tool call
- The process example and the user flow example show an intake round before their playback, and the gantt, ER and sequence examples name their reader
- The README's version row and release links name this release
