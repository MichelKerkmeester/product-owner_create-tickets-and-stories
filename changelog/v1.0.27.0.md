# v1.0.27.0, Browser-First ClickUp Pages and Mark-as-Done Between Dividers

A pushed doc page now reads like the team's own pages. A Story's Mark-as-done line has a rule on each side.

## What's New at a Glance

- **Doc pages are written in the browser.** `sk-product-owner` v1.2.15.0 pastes the page body in the editor. Dividers stay tight. Screenshot pairs land as columns
- **Numbers and Mark-as-done turn gray.** Numbered titles keep a gray, regular number. The Mark-as-done line reads gray italic
- **Mark-as-done sits between two dividers.** Templates, examples, the kernel and the gate carry it
- **The ClickUp packet carries the writer.** `mcp-click-up` v1.2.19.0 holds the page writer and its check

## Changed

- `sk-product-owner` moves to v1.2.15.0
- `vendor.json` pins `mcp-click-up` at the new upstream commit
- `AGENTS.md` names the browser-first push and the new divider rule
- Both format validators require a divider above and below a Mark-as-done line
- The README names this release
