# v1.0.16.0, Explicit Commands Ask First

A story test on DeepSeek V4.1 Flash high drafted on turn 1 in PST-003 and PST-004, after both `$s` and `$story`. The model quoted the rule that an explicit command asks first, then read the Story question template's "Populate only unresolved fields" as leaving nothing to ask when the sources looked complete. `sk-product-owner` v1.2.6.0 closes that reading.

## What's New at a Glance

- **An explicit command asks first, however complete the sources look.** The question then carries its Validation field, which no source settles, and waits for the answer
- **The reply linter reads the Delivery placeholder as a token.** `TBD...` no longer counts toward the one-ellipsis cap, as the Human Voice card already grants
- **Linter phrases match whole words only.** "acts as" no longer fires inside "contacts as"

## Changed

- The Project kernel moves to v1.2.16: its ESCALATE IF rule says sources that look complete do not answer the question
- `AGENTS.md` Section 5 states the same sentence
- `benchmark/grader/hvr_lint.py` bounds its phrase, metaphor and copula matches at both ends and skips `TBD...` in the ellipsis count
- The vendored `mcp-figma` and `mcp-click-up` copies are pulled to their upstream commits, which made their frontmatter valid YAML
- The README's version row and release links name this release
