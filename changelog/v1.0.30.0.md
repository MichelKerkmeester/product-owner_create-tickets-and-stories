# v1.0.30.0, Fresh Review Fixes and an Identifier Scan

A fresh review read the whole system with no prior context. This release fixes the findings Michel chose.

## What's New at a Glance

- **The gates lint the source.** `run_gates.sh` runs the format lint on the skill files. It ran only fixtures before
- **Scaffolds are linted too.** The example lint reads 44 fenced scaffolds. A banned em dash or semicolon fails it
- **Private identifiers fail a gate.** A new scan blocks a workspace id, a company email, a Figma team id and a home path
- **The repository is redacted.** 2,132 record files under `specs/` and `benchmark/reports/` lost those values
- **A broken manifest exits 2.** `vendor-sync.py` names the fault in one line. It printed a traceback before
- **Hub keywords match whole tokens.** `$document` and eleven look-alikes score no intent now
- **The grader reads the voice card.** Its word lists come from the card file, so they cannot drift

## Changed

- `sk-product-owner` moves to v1.2.17.0 and `sk-create-figjam` to v1.0.19.0, as their own notes list
- The Project kernel moves to v1.2.20
- The runner holds 19 gates, up from 15
- `vendor.json` pins the `mcp-click-up` and `mcp-code-mode` copies whose docs carry a placeholder workspace id
- `AGENTS.md` is 240 words shorter. The ClickUp Handoff paragraph points at the packet for the mechanics
