# v1.0.4.0, Boards That Show Their Links and Ask Before a Delete

The three-model FigJam comparison found six things to fix, from boards that hid their links to a model that deleted ten boards on a generic yes. `sk-create-figjam` v1.0.4.0 fixes all six.

## What's New at a Glance

- **Links you can see.** A gantt board draws an arrow for each dependency, and an ER board marks both ends of each relationship with its cardinality
- **A delete names its boards.** Flow Mode deletes a board only when a reply names it or the user says yes to a question that names it, never on a bare yes, and never deletes a board the conversation did not write unless the request is about it. Kernel v1.2.5 says the same for a revision's delete
- **Clearer recovery.** A missing file key no longer reads as a Figma outage
- **One verdict rule.** A board scenario passes only when its scorecard passes and every expected signal is present

## Changed

- The comparison's gallery rule ranks the board points first, so the gallery's process image is now SWE 2 Max's board
- The comparison's driver reads a board id from any `use_figma` result, and 21 of its exports were redacted again from raw after the runner's URL pattern had taken text glued to a URL
- The Project README gives the composer's new size: 1,170 lines and 47,148 characters, with about 2,850 characters left for the model and the `THEME` line
