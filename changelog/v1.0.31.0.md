# v1.0.31.0, Backlog Titles and a Sectioned Story Shape

Michel shared two Stories and his backlog names as the model. This release teaches both.

## What's New at a Glance

- **One title rule.** `AGENTS.md` states it once. A title is a label built from segments joined by ` - `
- **Build work leads with the team.** A Task or Bug opens on `FE`, `BE`, `FS`, `DATA` or `DS`
- **A missing team is asked for.** The one clarification question asks which team builds it. No team is guessed
- **A large Story can be sectioned.** Numbered requirement sections replace one flat list when the scope calls for it
- **One Story per platform.** Desktop and Mobile become sibling Stories when their requirements differ

## Changed

- `sk-product-owner` moves to v1.2.18.0, as its own note lists
- The Project kernel moves to v1.2.21. It carries the title rule and the Story shapes
- The Project holds 68 knowledge files, up from 67
- `leaf-manifest.json` is regenerated for the new example

## Upgrade

Paste kernel v1.2.21 into the Claude Project. Replace the knowledge files the packet note names.
