# v1.0.20.0, Doc Pushes Fix Their Own Gaps

A doc page push now checks how ClickUp imported the markdown and removes the empty line ClickUp writes under every divider, without a second question. `sk-product-owner` v1.2.8.0 sets the rule, and the vendored `mcp-click-up` v1.2.11.0 carries the program that does it.

## What's New at a Glance

- **Import check and gap removal on every doc push,** under the approval the push already has
- **Done means clean.** A push with a missing line or a gap left is not reported done

## Changed

- `sk-product-owner` moves to v1.2.8.0, as its own note lists
- `AGENTS.md` ClickUp Handoff states the same rule in one sentence
- The vendored `mcp-click-up` copy moves to v1.2.11.0
- The README's version row and release links name this release

## Upgrade

No Project file changes. The kernel stays at v1.2.16, and `sk-create-figjam` stays at v1.0.17.0.
