# v1.0.26.0, Side-by-Side Screenshots and Vendored Browser Packets

Design feedback compares a built screen with its Figma frame, and a ClickUp doc page can now show the two next to each other.

## What's New at a Glance

- **Screenshot pairs go in columns.** `sk-product-owner` v1.2.14.0 writes a `[[COLS-n]]` line for each DEV and FIGMA pair on a doc page push, and the columns routine builds the block after the gap pass
- **The ClickUp packet carries the routine.** `mcp-click-up` v1.2.18.0 holds the program and its check
- **The browser packets travel with the repository.** `mcp-aside-devtools` and `mcp-chrome-devtools` are vendored beside `mcp-click-up`, so a clone carries the setup and troubleshooting for the browser steps

## Changed

- `sk-product-owner` moves to v1.2.14.0, as its own note lists
- `vendor.json` gains the two browser packets, and `mode-registry.json` lists them as repository paths rather than modes
- `AGENTS.md`, the hub `SKILL.md` and the README name the browser packets
- The README's version row and release links name this release

## Upgrade

No Project file changes. A claude.ai Project pushes through its own ClickUp connector and has no browser for the editor steps. The kernel stays at v1.2.17.
