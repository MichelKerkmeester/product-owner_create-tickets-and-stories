# v1.0.9.0, Read the Board Twice

Claude Sonnet 5.5 high reran on v1.0.8.0 the 14 FigJam scenarios that had failed and passed 7 under the operator's two grading rulings. `sk-create-figjam` v1.0.9.0 fixes what the other 7 showed, and the playbook now reads every scored board with two readers.

## What's New at a Glance

- **A composite's states read second.** With no state named, a state board plans its first state first, the states inside a composite second and the end states last
- **The reply opens on the board URL.** The skill, `AGENTS.md`, the Project kernel and the Flow Mode Knowledge file say nothing comes before it
- **A revision's change wins the second glance.** A changed end other than a failure end is the second glance alone, and a revision that deletes the old section keeps the old title
- **The label check says when it skipped.** `flow_check.py` prints `Label: skipped` with the reason, and the Project's Flow Mode carries a hand rule for labels

## Changed

- One spelling for the second board of a split, `2. Workspace setup`, named under `Left out:` even when both boards sit in one file
- A second sticky on an adjacent row goes below or to the left of its node, the gantt example shows a missing-route gate and the style guide's 56 pixel rule is read on the composer's path estimate
- The playbook reads lanes and zones as frame and costs a Composition point only when both readers read a part early
- The README's version row and release links name this release
