## 8. WHAT WORKED

- Reading the gate's own routing function in-process (`check_hub.route_stage_one`) and replaying the 37 gold rows: proved consistency without running repo tooling or writing outside the lineage (iteration 1)
- Checking every `RESOURCE_MAP` path against disk and `leaf-manifest.json` with one scripted pass: turned a documented claim into a verified one (iteration 1)
- Counting documented totals from the tree with one script instead of trusting the prose: confirmed 62 knowledge files, 34+28 core/examples, 29 release notes, 141 router fixtures and 19 format fixtures, and isolated the one total that had drifted (iteration 2)
- Running `rule_parity.py` read-only: settled pair parity (62 of 62, 8 rules) and exposed the declared floor mismatch in the same call (iteration 2)
- Reading `scripts/build-plugin.py` against its own comment: one file comparison exposed a builder that ships 53 files its rule excludes (iteration 3)
- Measuring the built tree (`find` on `claude-plugin/skills`) instead of the script's claim: turned a plausible reading into a counted fact (iteration 3)
- Running the authoritative hub gate (`parent-skill-check.cjs`) with an absolute target path: 58 invariants green in one call, so the structural surface needs no further passes (iteration 4)
- Comparing a quoted gate output with a read-only run of the same gate: found the second stale count in the smoke matrix without re-reading the guide (iteration 4)
- Re-opening all nine active findings at their cited lines instead of trusting the earlier notes: all nine reproduced, so the verdict rests on the current tree (iteration 5)

## 9. WHAT FAILED

- Treating `ROUTER.md` section 3 as the enforced router: no gate parses that fence, so the header claim is documentation only (iteration 1)
- Searching `.skilled` with plain `find`: the `.skilled` symlink is not followed, so the first lookup for `leaf-resource-contract.cjs` returned a false negative until `find -L` was used (iteration 1)
- Assuming the documented parity method omitted the Flow packet: `SYNC.md:10` names both `sk-create-figjam` directories, so the candidate finding was refuted at the cited line (iteration 2)
- Expecting `benchmark/parity/run_parity.sh` to return a verdict: the shared gate refuses while its declaration file is uncommitted-modified (iteration 2)
- Trusting `build-plugin.py`'s "the playbooks stay out" comment: the exclusion set leaves `sk-create-figjam/manual-testing-playbook` in, which is the P1 of iteration 3 (iteration 3)
- Looking for a README the builder says it tracks: `claude-plugin/` holds no README (iteration 3)
- Passing a repository-relative target to the doctor gate: it resolves against the `.skilled` checkout root, so an absolute path is required (iteration 4)
- Sweeping every backticked path in a guide with one regex: packet-relative names and export examples produced false "unresolved" hits until each token was resolved against its own folder (iteration 4)
- Attempting to verify the smoke matrix's `59 cases` and `all 12 gates` rows: neither count has a static manifest to read, so both stay unverified rather than confirmed (iteration 5)
