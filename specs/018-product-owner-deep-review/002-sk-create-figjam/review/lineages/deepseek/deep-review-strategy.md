## 17. EXECUTION RETROSPECTIVE (hand-written)

Written after iteration 5, outside the machine-owned blocks the reducer owns.

**What worked.** Reading the check scripts and then *running* them decided more than reading alone did. Every threshold finding was settled by pairing the code line with the reference line, and the one P1 was only proved when a purpose-built nine-node, thirteen-connector user flow passed the check with exit 0 inside this lineage's `.scratch/` directory. The steering rulings in `steer.md` removed three whole question classes (write routes, mirror parity, the staging spec) before the first iteration, which is why five iterations were enough for four dimensions.

**What failed.** Two attempts at assuming a document was right. First, the assumption that `references/types/user-flow.md` set its own connector cap because the code carried `None` — the reference sets nodes only, so the code was the outlier, not the document. Second, the assumption that an unsupported `pie` header would surface as exit 2 through the vendored extractor's `_fail`; it surfaces as exit 1 through `UNSUPPORTED`, so a candidate finding was withdrawn after one run.

**Ruled out with evidence, so a later reviewer need not retry.** A wrong exit code for an unsupported kind; the style guide's seven-stroke arithmetic (seven accent strokes, 1.53:1 to 2.65:1, violet and pink above the 3.0 gate); `graph TD` as an accepted-header hole; the classic Mermaid arrow forms; over-long connector labels; the reply-line format; every cross-reference target; the vendored digest; all 81 local links; the 52-file playbook index; the ten-row palette table; the ten-step plan formula inside the archiver; and the process, architecture, sequence, state, ER and gantt budgets.

**Cost.** Five iterations, roughly 90 tool calls, all inside the read-only target and this lineage directory. No file in the reviewed packet was modified; the scratch models and their outputs stay under `.scratch/` as evidence rather than being deleted.
