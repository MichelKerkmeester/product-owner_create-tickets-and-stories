## Recommended Style Reference contract

Use one strict JSON block under a stable root key such as figjamStyleTokens, with schemaVersion 1. Keep the surrounding Markdown human-readable: purpose, role definitions, safe-use guidance, and a note about FigJam swatch behavior. Do not parse prose into design values. A typed/grouped JSON shape can borrow the organization pattern shown by public DESIGN.md and token examples, but the packet should define and validate its own bounded schema. [SOURCE: .skilled/skills/sk-design/sk-design-md-generator/assets/design-md-prompt-template.md:24-30,50-76; .skilled/skills/sk-design/sk-design-md-generator/references/design-md-format.md:28-45; https://github.com/stella/stella/blob/main/DESIGN.md:190-194; https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/:298-312,402-424]

The machine block should contain:

- Shared color roles as fill/stroke/text pairs by kind, plus named type-specific overrides for sequence messages, state markers, architecture lanes, ER relationships, gantt bars, and zones.
- Typography roles for title, subtitle, zone/key, node, edge, field/pin, and source line, with font family, size, and weight.
- Grid and spacing roles for board margin, title-to-body, node/rank gaps, zone header/padding/gap, key placement, and source-line placement.
- Shape type, stroke width, and rounding; rounding stays FigJam-native until the composer can apply and verify a numeric radius.
- Connector routing, color, width, dash, start cap, and end arrowhead by semantic edge role.
- Zone tint cycle and heading style; key background, heading, sample spacing, and order; white frame, title block, subtitle width/wrap, and source-line treatment.
- One first-glance accent token with the existing single-accent rule and type-specific focus targets.
- Contrast floors, documented palette exceptions, and a palette mode for FigJam swatches or custom colors.

The parser should reject unknown schema versions, duplicate blocks, missing required roles, invalid hex, invalid dimensions, unsupported connector values, and unsafe contrast. A missing file means the existing defaults. An invalid file means no board code is produced; report the exact token error before any board-write gate. This avoids a silent half-default/half-custom board. The FigJam API path remains one self-contained call because the Python layer injects validated JSON into the existing composer template.
