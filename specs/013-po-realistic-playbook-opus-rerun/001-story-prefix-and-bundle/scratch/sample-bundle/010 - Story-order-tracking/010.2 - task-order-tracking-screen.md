# Orders - Order tracking screen

### About

---

Shoppers open the order detail screen to find out where an order is, and today it shows only the order date. This task adds the status timeline to that screen, using the history the order status API returns.

### Requirements

---

### **Timeline**

---

1.  **Show the status timeline**

---

The shopper reads the timeline top to bottom and needs the latest status to stand out.

**Checklist**

- [ ] Show `Paid`, `Packed`, `Shipped` and `Delivered` in that order, with each reached status and its time
- [ ] Show the statuses the order has not reached yet as upcoming
- [ ] Show `Delayed` beside the latest status when the API marks the order delayed

**User Story**

- **Given:** a shopper with an order that has shipped
- **When:** they open the order
- **Then:** the timeline shows `Paid`, `Packed` and `Shipped` with their times, and `Delivered` as upcoming
