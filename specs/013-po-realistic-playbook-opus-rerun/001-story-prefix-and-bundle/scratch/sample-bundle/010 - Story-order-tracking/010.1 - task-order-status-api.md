# Orders - Order status API

### About

---

The order detail screen needs every status an order has reached, in order, with the time each one arrived. This task exposes that history from the carrier's status updates, so the tracking screen can draw a timeline without calling the carrier itself.

**Story**

---

- [Shopper - Orders - Order tracking](<010 - Story-order-tracking.md>)

### Requirements

---

### **Status history**

---

1.  **Return the order's status history**

---

The tracking screen reads one list per order. It needs the statuses in the order they happened and a flag for an order that stopped moving.

**Checklist**

- [ ] Return the statuses `Paid`, `Packed`, `Shipped` and `Delivered` an order has reached, oldest first, each with the time it arrived
- [ ] Mark the order `Delayed` when its latest status has no newer one after `48 hours`
- [ ] Return an empty history for an order with no carrier update yet, never an error

**User Story**

- **Given:** an order the carrier has marked shipped
- **When:** the tracking screen asks for its history
- **Then:** it receives `Paid`, `Packed` and `Shipped` in that order, each with its time
